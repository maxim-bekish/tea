Свободное пространство рядом с названием товара и под ценой оставлено намеренно. Это зоны под дополнительную информацию, которая обычно есть в карточке товара:

- рядом с заголовком можно расположить рейтинг и количество отзывов, число заказов, кнопка «Поделиться» и/или копирования ссылки;
- под ценой можно добавить краткую инструкция по завариванию, условия доставки и самовывоза.

Основной фокус задания — качество и структура вёрстки, поэтому визуальную часть я не перегружал, но придерживался фирменной цветовой гаммы Teaboom.ru.
